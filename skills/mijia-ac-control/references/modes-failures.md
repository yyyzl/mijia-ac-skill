# 模式适配与失败处理

首次切换制冷/制热模式，或 CLI 返回非零时读取。

## 模式适配

用户在本机查看目标设备 spec，将可读的 on、目标温度、mode 属性名写入私有配置。`mode_cool`、`mode_heat` 必须是该设备 spec 中对应的整数枚举；未知时停止模式写入。`status` 返回的是 mode 原始整数，不应凭常见型号经验把它解释成制冷或制热。

## 关机与回读

设备关机时，设温或切模式需要额外的开机许可。获得许可后 CLI 依次读取、开机、确认 on、写目标、确认目标与 on；缺少许可时不写入。已开机切模式也核对 on，意外关机应报告失败，不擅自恢复。

进程非零、超时、属性类型错误或回读不匹配时立即停止。报告 CLI 返回的固定错误、已确认的动作和未知状态；设备可能已改变。避免转发上游原始错误或设备清单，也不自动重试、补偿或回滚。云端 mode 与 on 回读匹配仍只是即时快照，物理制冷/制热需使用者单独观察。
