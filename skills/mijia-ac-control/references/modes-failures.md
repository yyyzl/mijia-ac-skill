# 首次模式适配或执行失败时读取

模式适配：用户本机核对 spec，填写 mode_cool/mode_heat 整数枚举和可读的 on/temperature/mode 属性。不能用猜测的枚举、siid/piid 绕过检查；不兼容就停止。

关机设温/模式：无开机许可零写入退出；许可后顺序为读取、显式开机、独立确认 on、写目标、独立确认目标及 on。已开机的模式操作也核对 on，意外关机作为失败报告，不擅自恢复。

进程非零、超时、非法类型或回读不匹配：立即停止，不回滚、不重试；说明失败阶段、已发生或可能发生的副作用与未知状态。只转述 wrapper 固定错误，不转发上游敏感输出。回读匹配不能证明物理制热；需要使用者单独观察物理效果。
